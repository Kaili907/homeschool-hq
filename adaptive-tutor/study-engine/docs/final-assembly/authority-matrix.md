# Unified authority matrix

| Decision | Sole authority | Explicit non-authorities |
|---|---|---|
| Mastery, misconception, prerequisites, reteaching, instructional directive | Tutor Core 0.2 | Study Engine, parent runtime, bridge |
| Canonical Study shapes, states, task types, versions | Session 1 | Provisional adapters and vendor snapshots |
| Pacing, break, review, interleaving recommendation | Session 2 | Tutor event DTOs |
| Safety gate, permits, compatibility, ledger, minimization, quarantine | Session 6-R2 | Student UI and external host |
| Student progress, timer presentation, break, checkpoint/resume, Jarvis presentation | Session 7-R2 | Calendar runtime |
| Review queue, placement, continuation, parent controls/evidence, timezone, Romeo | Session 8-R3 | Session 4 provisional roots |
| Public composition and release compatibility | Session 9 | Frozen/accepted component internals |

The composition callback constructs, starts, and submits to Tutor Core only after the bridge grants a clear one-time permit. Session 9 derives its public `continue`/`reteach` directive from the accepted bridge recommendation, never from an engine snapshot.
