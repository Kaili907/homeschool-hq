# Foundation corpus

The corpus contains 128 deterministic scenarios: four grade/subject variants for each of 32 equally weighted primary categories. The variants cover early elementary, upper elementary, middle school, and high school across math, ELA, science, and social studies.

Fixtures intentionally include both safe Tutor behavior and prohibited/malformed/outage behavior. Prohibited behavior is paired with explicit rejection or fallback expectations, so the corpus checks that policy enforcement recognizes the condition rather than rewarding the bad response.

All content is synthetic and uses opaque fixture references. No live provider, learner record, credential, raw transcript store, or production runtime is accessed.
