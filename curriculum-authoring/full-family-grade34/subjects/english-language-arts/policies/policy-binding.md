# Policy Binding

This package does not restate or fork Manuel Academy policy. It binds to the existing policy set and adds only what Grades 3 and 4 English Language Arts require beyond it.

## Bound, unmodified

| Policy | Location | What it governs here |
| --- | --- | --- |
| Instruction, mastery, accessibility, safety, and privacy | `curriculum-content/manuel-academy/1.0.0/policies/instruction-mastery-accessibility-safety.md` | The instructional commitments, the mastery rule, the accessibility floor, the privacy floor, the sensitive-history-and-literature rule, and the technology and AI rule. |
| Shared rubrics | `curriculum-content/manuel-academy/1.0.0/shared/rubrics.md` | The four-level mastery rubric, the writing and communication rubric, and the collaboration and discussion rubric used by every assessment in this package. |
| Student learning tools | `curriculum-content/manuel-academy/1.0.0/shared/student-learning-tools.md` | The explain-your-thinking frame, the claim-evidence-reasoning frame, and the source record used by the research units. |
| Teacher and tutor tools | `curriculum-content/manuel-academy/1.0.0/shared/teacher-and-tutor-tools.md` | The reteaching decision routine and the parent summary template. |
| Standards reference and frozen baselines | `curriculum-content/manuel-academy/1.0.0/standards/standards-reference.md` | The jurisdictional posture and the frozen-artifact register. |

Nothing in those files is edited, copied, or superseded by this package.

## Added by this package

These four documents state commitments that are specific to Grades 3 and 4 English Language Arts and that the shared policy set does not spell out at this level of detail.

| Document | Adds |
| --- | --- |
| `accessibility.md` | The per-lesson accessibility guarantees, including the text-only path, the no-audio path, and the private presentation alternative, stated as machine-checkable lesson fields. |
| `source-integrity.md` | The text and copyright rules for a literacy course: original, public-domain, short lawful excerpt, and learner- or family-selected texts, each with required provenance metadata. |
| `academic-integrity.md` | Student authorship of assessed writing, fixed-answer protection, and the raw-response persistence boundary. |
| `adaptive-english-boundary.md` | The relationship between these two courses and the frozen Adaptive English package. |

## Precedence

Where this package and the shared policy set both speak, the shared policy set governs and these documents are read as a stricter local application of it. If a genuine conflict is ever found, it is a defect in this package and should be reported rather than resolved in favor of the local document.
