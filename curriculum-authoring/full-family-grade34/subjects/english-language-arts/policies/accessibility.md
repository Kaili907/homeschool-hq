# Accessibility — Grades 3 and 4 English Language Arts

Every lesson in both courses carries the guarantees below as structured fields, so they can be verified mechanically rather than asserted in prose. `tools/validate.py` fails the package if any lesson is missing any of them.

## Per-lesson guarantees

1. **Text-only path.** Every lesson can be completed entirely from readable text. No image, audio, video, chart, or diagram is required to reach the target. At Grade 4, where a standard requires interpreting visual or quantitative information, the package supplies a written description that carries the same information, so the standard is met without sight of the visual.
2. **Read-aloud capable content.** All reading content is plain text suitable for an adult reader, a screen reader, or a text-to-speech tool. The learner is never required to read aloud.
3. **No-audio path.** Any listening task may be completed from a printed transcript or script instead. This includes the standards that name listening or media directly.
4. **Captions and transcripts when media exists.** If media is used at all, captions and a transcript are required. Media without both is not used.
5. **Private presentation alternative.** Every speaking, reporting, presenting, or discussion task may be delivered privately to one adult, submitted in writing, typed, or displayed silently.
6. **No required learner voice or video.** No task requires recording the learner's voice or image. Where a standard names audio recording, the learner may satisfy it with a written script and a silent visual display, or with an adult-read recording. Learner voice is never stored without explicit guardian opt-in.
7. **Chunked directions and a worked example.** Directions are given one action at a time and a model is available for every task.
8. **Alternate response modes.** Typed, handwritten, spoken, dictated-to-a-scribe, drawn, or organizer-based responses are accepted whenever the standard does not itself name the response mode.
9. **Access supports on request.** Reduced copying, extended time, hidden timers, movement breaks, high-contrast print, larger type, keyboard access, and low-distraction settings are available on request.

## The target is preserved

Access supports change quantity, pacing, representation, setting, or response mode. They do not change the standard being assessed. Using a support is never recorded as a failure and never appears in a mastery decision. Swapping to a shorter text at the same target is an access decision, recorded as such, not a mastery result.

## Where the standard names the mode

Three standards name a mode that could otherwise conflict with these guarantees.

| Standard | Named mode | How this package satisfies it accessibly |
| --- | --- | --- |
| `3.SL.5` | create audio recordings of stories or poems | A written script plus a silent visual display, or an adult-read recording, satisfies the target. Learner voice is opt-in. |
| `4.SL.5` | add audio recordings and visual displays to presentations | Same. The visual display always carries a text description. |
| `3.SL.6`, `4.SL.6` | speak in complete sentences; use formal English when appropriate | Register and completeness may be demonstrated in writing or typed contribution. Speaking aloud is one option, not a requirement. |
| `3.RL.7`, `4.RL.7` | explain what a text's illustrations or a visual presentation contribute | This package ships no images. The visual comes from the learner's own illustrated copy, a library or public-domain edition, or a described figure the facilitator supplies. A learner who does not see images meets the same target from the description, which is what the standard asks the learner to reason about. |
| `3.RI.7`, `4.RI.7` | use information from illustrations, maps, charts, diagrams, or timelines | Same sourcing. Grade 4 Unit 5 Day 11 makes the text-only description itself the graded work, so writing the replacement for a visual is assessed as a skill rather than treated as a workaround. |

## Reading difficulty is not a character judgment

Both courses use non-shaming language about decoding, spelling, handwriting, speech difference, accent, and pace. A pause, a break, or a change of response mode is never recorded as a failure, and an error is treated as evidence for the next instructional move.
