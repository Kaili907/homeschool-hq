# Technology and Computer Science — Projects and Portfolio Tasks (Grades 3–4)

Every unit ends with a performance task (see each unit's `performance_task` in `units.json` and the
`"Performance task build"` / `"Application or project"` lesson phase) that becomes one artifact in the
learner's technology portfolio. No performance task requires a real account, real credentials, a live
public deployment, or contact with a real external system.

## Grade 3 (`ma-g3-tech-cs`) unit projects

| Unit | Project |
| --- | --- |
| 1 | Digital-safety poster using fictional examples and no real personal information |
| 2 | Labeled diagram of computer parts plus a demonstration of three careful-use habits |
| 3 | One clearly named, organized digital or paper folder of practice work |
| 4 | A tested, step-by-step set of directions for a partner or character to follow |
| 5 | A small collected data set turned into a simple picture graph with a short conclusion |
| 6 | A simple prototype, paper or digital, that solves a problem for a chosen user |

**Capstone:** a simple, accessible prototype with step-by-step directions, a test note, and a short
presentation or demonstration — presentable publicly, privately, in writing, or through a demonstration.

## Grade 4 (`ma-g4-tech-cs`) unit projects

| Unit | Project |
| --- | --- |
| 1 | A digital-safety guide for a younger learner, fictional examples only, no real credentials |
| 2 | A troubleshooting flowchart for a common device problem |
| 3 | An accessible one-page document or short slide set on a class topic |
| 4 | A short story, animation, or simple game built with block-based logic, with the algorithm documented |
| 5 | A short data story with a chart, cited or original media, and a source-check note |
| 6 | A tested and improved prototype that helps a real or fictional user, with a short presentation |

**Capstone:** a user-centered prototype with an algorithm, a test log, an accessibility check, and a
presentation — presentable publicly, privately, in writing, or through a demonstration.

## Portfolio evidence and grading

Each project is scored with the shared assessment rubric in the unit's `assessments.json` entry
(`rubric_dimensions`: accuracy or fidelity; evidence and reasoning; application or performance; checking
and revision) plus the `performance evidence` prompt, which asks the learner to present the strongest
evidence from the unit project directly. Guardians see the target, completion state, evidence type, and
next step for each project — not raw answers or private reflections. AI or adult assistance may support
brainstorming, explaining, or debugging, but the submitted project must be the learner's own work.
