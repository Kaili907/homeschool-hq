# Grade 4 Mathematics - Course Guide

**Course ID:** `ma-g4-mathematics`  
**Version:** 1.0.0  
**Instructional sessions:** 180  
**School year:** 36 weeks at 5 instructional days per week  
**Typical session:** 40-55 minutes  
**Cadence:** daily

## Course description

A complete fourth-grade mathematics course built directly from the Grade 4 Michigan mathematics domains. Every unit moves from concrete representation to reasoning to independent evidence, and no unit treats a single correct answer as proof of learning.

This course is original Grade 4 sequencing. It is not a simplification of the Manuel Academy Grade 5 mathematics course, and it shares no lesson content with it.

- Grade 4 fractions are limited to denominators 2, 3, 4, 5, 6, 8, 10, 12, and 100.
- Grade 4 base-ten work is limited to whole numbers less than or equal to 1,000,000.

## Course outcomes

By the end of the course, learners will:

1. Demonstrate the Grade 4 Michigan mathematics standards through independent, accessible evidence.
2. Explain reasoning with a model, calculation, or documented process rather than an unsupported answer.
3. Transfer a learned idea to an unfamiliar problem or situation.
4. Use error evidence to revise, without shame or character judgment.
5. Complete the course capstone: **Capstone: design a symmetric plan for a garden, room, banner, or game board using measured angles, classified shapes, and a generated pattern, with a full written justification.**

## Mastery and grading

- **One correct response never establishes mastery.** This is the canonical Manuel Academy rule and it is enforced structurally: each unit provides 4 independent-evidence occasions on separate days, plus an assessment and a reassessment occasion.
- Instruction, guided practice, independent evidence, and reassessment are recorded as different kinds of evidence and are never collapsed into one number.
- Guided success is not weighted the same as independent success.
- Reassessment requires fresh items. A reused item cannot establish new evidence.
- Suggested reporting: **Secure**, **Developing**, **Not Yet**, supported by evidence rather than a single percentage.
- A pacing concern is not a mastery failure. Speed is never scored and never reported as a result.
- Parent summaries show target, completion, evidence type, and next step. They exclude raw answers, private reflections, recordings, and diagnosis language.

## Adaptive Math compatibility

Grade 4 overlaps the frozen Adaptive Math intervention package (grade band 4-6). Where a unit's skills genuinely align with one of that package's four sequences, the unit carries a capability marker so an adult may route a learner to the intervention after static repair has been tried. The frozen package is referenced only - never copied, rewritten, or modified.

| Unit | Aligned frozen sequence |
| --- | --- |
| 1 | Place Value and Regrouping |
| 2 | Place Value and Regrouping, Multistep Word-Problem Reasoning |
| 3 | Multiplication and Division Relationships |
| 4 | Multiplication and Division Relationships, Multistep Word-Problem Reasoning |
| 5 | Multiplication and Division Relationships, Multistep Word-Problem Reasoning |
| 6 | Equivalent Fractions and Common Denominators |
| 7 | Equivalent Fractions and Common Denominators |
| 8 | none - static fallback only |
| 9 | none - static fallback only |
| 10 | none - static fallback only |

**Every Grade 4 unit is complete without the adaptive package.** Units 8, 9, and 10 have no aligned sequence at all, and they function exactly like the rest of the course.

## Accessibility

No camera, no identifiable photograph, and no voice input is required at any point in this course. Every lesson has a complete text-only path, every representation is described in words, every diagram is static and reduced-motion safe, and every learner task can be completed on a small touch screen or on paper. See `accessibility-no-media.md`.
