# Verified-identity academic runtime adapter

The browser receives an exact envelope containing schema version, status, one opaque session reference, and expiry. Household, learner, grant, membership, relationship, capability, revision, and epoch authority remain server-internal.

`study-academic-runtime` accepts the opaque bearer, rejects caller-supplied identity and production sentinels, hashes the reference locally, maps the operation to an exact capability, and invokes one transactional RPC. The RPC must derive the household/student/grant binding and recheck current membership, relationship, purpose, scope, expiry, revocation, session version, authorization revision, and schema marker before any mutation.

The browser generation and abort controller quarantine late UI results. They do not replace transactional server authorization.
