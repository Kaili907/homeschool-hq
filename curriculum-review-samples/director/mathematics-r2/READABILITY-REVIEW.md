# Manual age and readability review

Reviewed against the R2 language bands and the frozen R1 shared production
teaching standard.

| Grade | Manual inspection | Result |
| --- | --- | --- |
| 3 | Short sentences, one action per direction, concrete place-value chart, immediate definitions, no curriculum-director voice | Pass |
| 4 | Concrete digit tracking, short comparison prompts, explicit place names | Pass |
| 5 | Child-friendly decimal vocabulary, chart before abstraction, zeros explained in context | Pass |
| 7 | Mature unit-rate language, table/equation/context connections, steps remain scannable | Pass |
| 8 | Rational/irrational precision without childish phrasing, misconception separated explicitly | Pass |
| 9 | Concise algebraic reasoning, sign reversal justified by order and number-line reflection | Pass |
| 10 | Coordinate and transformation language is precise; composition and invariants are defined | Pass |
| 11 | Implication, equivalence, domain, and verification are used at appropriate sophistication | Pass |
| 12 | Unit-circle derivations use coordinate transformations rather than memorized quadrant slogans | Pass |

Every sample labels the worked example as answer-bearing instruction, changes
visibly to “Your turn” or practice before requesting input, supplies an existing
response kind, offers specific non-shaming feedback, includes a different
reteach representation with a fresh item, and ends in the structured lesson
review contract. No sample relies on Tutor availability.
