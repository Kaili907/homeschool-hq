# Limitations

- The package supplies English curriculum, deterministic fixtures, and a local demonstration; it does not provide persistence, identity, authentication, or progress synchronization.
- Browser speech depends on the browser’s optional speech-synthesis capability. Captions, transcript, and text-only board content remain available when speech is absent.
- Multiple-choice fixtures demonstrate deterministic Core assessment transitions. Open-ended paragraph revision remains learner-owned and is not automatically scored as mastery.
- The package does not diagnose dyslexia, disability, or any medical or psychological condition.
- Parent/teacher notes summarize observable learning evidence and are not placement decisions.
- The demo stores an entered revision only in the current page memory and sends it nowhere.
- No camera or identifiable photo path exists.
