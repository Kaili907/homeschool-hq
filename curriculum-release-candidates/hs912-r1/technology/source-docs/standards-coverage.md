# Standards Coverage — Technology and Computer Science, Grades 9–12

**Framework:** Michigan K-12 Computer Science Standards (CSTA-2017-derived concepts)

Michigan's computer-science standards are derived from the CSTA 2017
framework, which defines **five** core concepts. Cybersecurity is a *subconcept
of Networks and the Internet*, not a sixth concept; it is tracked separately
here only because this sequence gives it dedicated units, and it is labelled to
show its parent concept. Anchors are recorded as prose concept labels, matching
the Grade 5/7/8 release convention — no state standard codes are invented.
