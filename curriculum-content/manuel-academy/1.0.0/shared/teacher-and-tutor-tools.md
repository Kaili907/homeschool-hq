# Teacher and Tutor Tools

## Daily planning card

- Lesson ID and target
- Prerequisite retrieval prompt
- Model or source to prepare
- One guided example
- Independent application
- Exit ticket
- Anticipated misconception or support need
- Accessibility choices
- Safety/guardian requirement
- Evidence to retain
- Next review date or condition

## Reteaching decision routine

1. Identify the smallest observable gap.
2. Check whether the barrier is prerequisite knowledge, representation, vocabulary, task interpretation, access, or a repeated misconception.
3. Change the explanation or representation rather than merely repeat it louder or longer.
4. Practice one supported example.
5. Use one fresh independent check.
6. Schedule retrieval later; do not declare mastery from the immediate retry.

## Parent summary template

“Today’s target was ____. The learner completed ____. Evidence included ____. The next instructional step is ____. The following support or accommodation was used: ____. No action is needed / Please help with ____.”

Do not include raw answers, raw transcripts, diagnosis language, private reflections, or hidden behavioral scores.

## Project conference prompts

- What problem, question, audience, or purpose guides this work?
- Which standards or criteria matter most?
- What evidence supports the current decision?
- What is uncertain or incomplete?
- What did testing or feedback change?
- What safety, privacy, accessibility, cultural, source, or fairness issue must be checked?
- What will the learner complete independently next?
